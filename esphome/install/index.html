Tempem remote gateway

Firmware {{VERSION}} for ESP32-C6 boards (e.g. DFRobot FireBeetle 2 ESP32-C6). Release notes

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. The installer only works on an https:// page.

Connect the board with a USB data cable, click Install and pick its serial port.

First install

  1. Click Install, choose the board's port (USB JTAG/serial debug unit on ESP32-C6), then Install Tempem remote gateway. On a board that ran other firmware before, tick Erase device.
  2. When it's done, the installer asks for Wi-Fi. Pick the network of the site where the gateway will run. You can also skip this and set the Wi-Fi on site: the gateway then opens the hotspot Tempem-Remote-Setup, and joining it with a phone shows a page to choose the network.
  3. Click Visit device (or open http://<its IP>/). Paste the Webhook URL from Home Assistant into the field of the same name and press Enter.
    In Home Assistant: Settings → Devices & services → Add integration → Tempem BLE → Add a remote gateway.

Within a minute the gateway shows as connected in Home Assistant, and the beacons around it appear under Discovered.

Updates

  1. Automatic (default): the gateway checks for a new release twice a day and installs it itself. If a new version fails to start, it rolls back to the previous one. Turn this off with the Auto-update switch on its web page.
  2. From its web page: press Check for firmware update, or upload tempem-remote-gateway.ota.bin from a release in the OTA Update box.
  3. Over USB: click Install on this page again and leave Erase device unticked. Wi-Fi and the webhook URL are kept.

No Install button?

Use a desktop Chrome or Edge, and a USB cable that carries data. If the port doesn't show up, hold BOOT, tap RST, release BOOT, and try again. Linux users may need to be in the dialout group.
